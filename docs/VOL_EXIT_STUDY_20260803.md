# 변동성 기반 청산 — 제4의 축은 랭크 청산을 못 넘는다 (2026-08-03)

착상(사용자): 랭크 청산이 "모델 의견이 나빠지면 판다"라면, **변동성 변화로도**
매도 타이밍을 잡을 수 있지 않나. 국면 변화까지 함께 보면서.

정보원이 다르므로(예측 vs 실현변동성) 시간·가격·랭크에 이은 제4의 축이 될
수 있다. `scripts/vol_exit_study.py`, ens_s r5 6시드 / r4 3시드, 41bp,
전부 인과(보유 s일차 판정은 s−1 세션까지만).

## 읽어낸 것

### 1. 랭크 청산이 여전히 압도적이다
+1.98 vs 변동성 계열 최고 +0.81. 두 배 넘는 격차다. 변동성이 담은 청산 정보는
**모델 예측 랭킹에 이미 대부분 들어 있다**고 보는 게 맞다.

### 2. `vol_up` 은 임계를 느슨하게 할수록 좋아진다 — 트리거가 해롭다는 뜻
1.3x(+0.49) → 1.5x(+0.57) → 2.0x(+0.70). 보유일도 21.3 → 24.2 → 27.5 로 늘어난다.
**임계가 느슨해져 거의 발동하지 않을수록 성적이 좋아진다** = 발동 자체가 손해다.
"변동성이 튀면 판다"는 좋은 종목을 겁먹고 던지는 쪽에 가깝다.

### 3. `regime_up` 은 폴드가 정반대다
r5 +0.99 / r4 −0.10. 국면 악화 신호로 파는 것은 재현되지 않는다.
2×2 의 "고국면은 예측 불가능"과 일관된다 — 예측 불가능한 신호로 청산 타이밍을
잡으려 한 셈이다.

### 4. ⚠️ `adaptive 2×2` 가 완전히 실패했다 — 가장 중요한 결과
2×2 교차 결론(저국면·고종목 → D+5, 저국면·저종목 → D+15, 고국면 → D+5)을
**그대로 규칙으로 옮겼더니 +0.00** 이 나왔다. 평균 보유 5.2일로, 대부분이
D+5 분기를 탔고 D+5 단독(+0.21)보다도 못하다.

2×2 표에서 `저국면·고종목 D+5 = +0.93` 이었는데 그걸 규칙화하면 0 이 된다.
**셀별 패턴은 서술적일 뿐 실행 규칙으로 전이되지 않는다.** 이유는 표가 사후
분류(그 셀에 속한 관측만 모아 잰 것)인 반면, 규칙은 진입 시점에 셀을 **예측**해
행동해야 하기 때문이다. 국면·종목변동성 분류가 보유기간 동안 유지된다는 보장이 없다.

→ 어제 2×2 문서에서 "판정 불가, 5폴드 필요"로 유보한 것이 옳았다. 5폴드에서
   패턴이 확인되더라도 **규칙화까지 별도 검증이 필요하다**는 것이 여기서 드러났다.

## 판정

**변동성 기반 청산은 채택 후보가 아니다.** D+15 를 근소하게 넘는 변형이 있으나
(either +0.81, vol_up 2.0x +0.70) 랭크20(+1.98)에 크게 못 미치고, 폴드 일관성도
없다. 랭크 청산을 두고 굳이 이걸 쓸 이유가 없다.

부수 소득 두 가지:
- 랭크 청산의 우위가 다른 정보원과 비교해도 견고하다는 방증.
- 2×2 같은 조건부 표를 규칙으로 옮길 때의 함정을 실측으로 확인했다.

5폴드 확인은 `run_s0_studies.sh` 에 S0-h 로 넣지 않는다 — 2폴드에서 이미
랭크20 대비 격차가 크고 방향이 명확해 GPU 세션의 우선순위가 낮다.
필요하면 `python scripts/vol_exit_study.py --folds r5 r4 r3 r2 r1` 로 언제든 CPU 재실행.
