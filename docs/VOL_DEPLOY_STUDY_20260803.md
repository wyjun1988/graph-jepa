# 배분 조절(vol deployment) 변형 연구 — 프로덕션 K 의 부호가 반대다 (2026-08-03)

`scripts/vol_deploy_study.py`. 청산은 고정하고 배분 배수만 바꾼다:

    m_t = clip(1 + K·z_t, lo, hi),  z_t = (최근 W세션 실현변동성의 ZW세션 z-score)

프로덕션(`paper_trader.py` VS_K/VS_VOL_WIN/VS_Z_WIN): **K=+0.3, W=20, ZW=40,
clip(0.2,2.0), 신호원 KQ11**. K>0 = 변동성이 높을 때 **더 싣는다**.
근거는 "4시드 OOS 최적" 주석뿐이고 5폴드 검증이 없었다.

ens_s, r5 6시드 / r4 3시드, 41bp. m=1 이면 기존 결과와 정확히 일치한다.

## 읽어낸 것

1. **프로덕션 K=+0.3 이 '고정(m=1)' 을 못 넘는다.** D+15 +0.43 vs +0.57,
   rank20 +1.42 vs +1.98. 배분 조절을 아예 끄는 게 낫다.
2. **K 가 커질수록 단조로 나빠진다** — 두 폴드·두 청산 **네 조합 모두에서**.
   0.15 → 0.30 → 0.45 → 0.60 이 예외 없이 하락한다. 노이즈가 아니라 방향성이다.
3. **부호가 반대다.** K<0(변동성 높을 때 덜 싣는다)이 이긴다. rank20 에서는
   **두 폴드가 모두 동의**한다(K−0.3: r5 +1.72>+1.32, r4 +2.62≈+2.64).
   D+15 에서는 r5 만 강하게 선호하고 r4 는 반대라 폴드 불일치가 있다.
4. clip 을 좁히면(.8–1.2) 성능이 회복된다 — **조절 폭을 줄일수록 좋아진다**는
   것도 "조절 자체가 해롭다"와 같은 방향의 증거다.

## ⚠️ 라이브 1위는 알파가 아니라 레버리지일 수 있다

페이퍼에서 `vol스케일` 이 계속 1위다(2026-08-03 +3.58%, 정정 헤지). 그런데
`결합`(사다리×conf×μ, 배분조절 없음)과 **배분 조절 하나만 다르다**: +1.82% vs +3.58%.

배분 배수 평균이 **m≈1.05~1.12**(위 표)이고 페이퍼 기간 최근값은 1.18~1.23 이었다.
즉 vol스케일은 이 구간 내내 결합보다 **10~20% 더 싣고** 있었다. 수익이 난 구간에서
더 실으면 손익은 비례해 커지지만 **Sharpe 는 개선되지 않는다** — 위 백테스트가
재는 것이 정확히 그 Sharpe 이고, 답은 "나빠진다"이다.

**라이브 순위표의 vol스케일 1위를 알파로 읽으면 안 된다.** 2주·8코호트 표본에서
상승 구간에 레버를 올린 결과일 가능성이 크다. 변동성이 뛴 뒤 하락하는 구간에서는
같은 규칙이 반대로 작동한다.
