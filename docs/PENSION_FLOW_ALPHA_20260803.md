# 연기금 흐름 알파 — 상한선은 크고, 이미 아는 부분은 값이 없다 (2026-08-03)

착상(사용자): 국민연금이 뭘 살지 예측하면 플러스 알파가 있을 것이다. 큰 매수/매도니까.
연기금 보유를 노드로 놓고 미관측 시점을 예측하거나 리밸런싱 타이밍을 예측하면 어떤가.

## 먼저 — 이미 있는 것부터

4. **그리고 잘 예측한다.** 피처군별 `pooled_mse_skill_vs_persistence`(ens_s3, r5):

### 읽어낸 것

1. **상한선이 크다.** RankIC 0.22~0.24. 챔프 모델의 h10 IC 가 0.05 대인 것과 비교하면
   **4~5배**다. 완벽히 안다면 압도적이다.
2. **과거 연기금 흐름은 오히려 마이너스다.** known_past IC −0.02~−0.04, Sharpe 음수.
   "연기금이 산 걸 따라 사는" 전략은 손해다. 현재 모델 입력인 그 피처는 방향성
   알파를 주지 않는다(다른 역할은 할 수 있다).
3. **가치는 전부 '아직 모르는 미래분' 에 있다.** oracle−known ≈ oracle 이다.
   이미 활용된 부분이 사실상 없다.

## ⚠️ 상한선을 그대로 믿으면 안 되는 이유

**동시성 문제.** 오라클은 t+1~t+h 의 연기금 순매수와 같은 구간의 수익률을 맞대었다.
연기금이 사는 **동안** 가격이 오르는 것이라면(가격충격), 그건 예측이 아니라 동행이다.
t 시점에 예측해 t+1 시가에 사면 그 움직임을 실제로 먹을 수는 있지만, **예측
가능성**은 별개 문제다. 연기금이 가격을 보고 사는 것이라면(모멘텀/역추세 매매)
수급 예측은 수익률 예측만큼 어렵다.

또한 h1 의 MSE skill +0.50 은 **persistence 대비**이고, 노이즈가 큰 계열에서
persistence 는 약한 기준이다. **MSE 정확도 ≠ 랭킹 IC** 라 그대로 옮겨 읽으면 안 된다.

## 다음 단계 (비용 순)

   알파가 대부분 사라지면 가격충격 동행이고, 남으면 진짜 선행성이다.
2. **예측 가능성 측정 (재학습 불필요, 재평가만).**
   `evaluate_node_prediction.py:1091` 의 `optional_forecast_names` 튜플에

   그 다음 `예측된 연기금 흐름` 의 RankIC 를 오라클(0.22)과 대조한다.
   그 비율이 이 아이디어의 실제 값어치다.
3. **선택 신호에 반영 (그때 가서).** 2번이 유의미하면 진입 랭킹을

**지금 프로덕션은 건드리지 않는다.** 1·2번이 나오기 전에는 상한선만 아는 상태다.

## 동시성 분리 실측 (2026-08-03 추가)

보유는 t+1~t+10 로 고정하고 **신호 구간만 뒤로 밀며** RankIC 를 다시 쟀다.

| 신호 구간 | 수익률 구간과 겹침 | RankIC |
|---|---:|---:|
| t+1~t+10 (원본) | 10일 | +0.2363 |
| t+6~t+15 | 5일 | +0.2109 |
| **t+11~t+20** | **0일** | **+0.1016** |
| t+16~t+25 | 0일 | +0.0564 |
| t+21~t+30 | 0일 | +0.0338 |

**해석 — 두 성분이 섞여 있다.**

1. **동행 성분(가격충격/동시 매집)**: 겹침이 10일 → 0일로 가면 IC 가
   0.236 → 0.102 로 **57% 사라진다.** 절반 이상이 "사는 동안 오른다"는 동시성이다.
2. **후행 성분**: 겹침 0인데도 +0.10 이 남고, 더 밀수록(t+16~, t+21~) 0.056 → 0.034
   로 감쇠한다. 즉 **연기금은 오른 뒤에도 계속 산다**(모멘텀 추종/분할 매집).
   이건 "이미 지나간 가격의 반영"이라 알파가 아니다.

**따라서 진짜 가용 알파는 0.236 전부가 아니다.** 예측 시점 t 에서 t+1 에 진입해
t+10 까지 보유한다면 동행 성분은 먹을 수 있지만, 그러려면 t 시점에 **아직 일어나지
않은** 매수를 맞혀야 한다. 후행 성분(0.10)은 t 시점에 이미 관측된 가격에서 나오므로
모델이 이미 쓰고 있는 정보다.

낙관적으로 봐도 가용 상한은 **0.236 − 0.102 ≈ 0.13** 수준이고, 그중 실제로
예측 가능한 비율만큼만 남는다. 그래도 챔프 h10 IC(0.05 대)의 2배가 넘는 자리라
**여전히 확인할 값어치가 있다.**

### 왜 음수인가 — 앞의 분해와 정확히 맞물린다

오라클 분해에서 `known_past`(과거 연기금 흐름)의 IC 가 −0.02~−0.04 였다.
모델의 수급 예측은 **최근 흐름의 외삽에 크게 기댄다**(그래서 persistence 대비
MSE skill 이 +0.50 으로 높았다). 즉 모델이 맞히는 것은 연기금 흐름의
**지속적·예측 가능한 성분**인데, 그 성분이 바로 후행분(오른 뒤에도 계속 산다)이라
선도 알파가 없다. 오히려 역추세라 부호가 음수다.

정리하면:

| 연기금 흐름의 성분 | 크기(IC) | 예측 가능? | 알파? |
|---|---:|---|---|
| 동행(가격충격·동시매집) | ~0.13 | **불가** | 있음(못 먹음) |
| 후행(모멘텀 추종·분할매집) | ~0.10 | 가능 | **없음**(음수) |

**알파가 있는 성분은 예측이 안 되고, 예측되는 성분은 알파가 없다.**
MSE 정확도(+0.50)가 랭킹 알파로 전이되지 않는다는 앞선 경고가 그대로 실현됐다.

## ⚠️ 정정 — 위 결론은 틀렸다 (2026-08-03, 같은 날)

반박(사용자): *오라클로는 되는데 우리가 실패한 거면, 우리 예측이 못하는 것 아닌가.*

맞다. 위의 "알파 있는 성분은 예측 불가, 예측되는 성분은 알파 없음"은 **측정이 아니라
추론**이었고, 재보니 틀렸다. 두 가지 결함이 있었다.

**결함 1 — 대상이 어긋났다.** 오라클은 `t+1~t+h 누적 순매수`로 쟀는데
모델이 예측하는 것은 `t+h 시점의 1일 흐름비율`이다. 서로 다른 물건을 놓고
"오라클은 되는데 예측은 안 된다"고 했다.

**결함 2 — 예측 품질을 재지 않았다.** MSE skill(+0.50)만 보고 "잘 예측한다"고 했다.
그건 전 셀 평균 오차이지 **횡단면 랭킹 정확도**가 아니다.

### 재측정 (챔프 3시드, r5, 194일, 지평 10)

**[1] 예측 품질 — 모델이 자기 목표를 맞히나**

| | 순위상관 |
|---|---:|
| corr(모델 예측, t+h 1일흐름 실제) | **+0.1117** |
| corr(직전 1일흐름, t+h 1일흐름 실제) = **persistence** | **+0.2096** |

**모델이 순진한 persistence 보다 못하다.** 어제 흐름을 그대로 쓰는 것보다
모델 예측이 나쁘다. MSE skill +0.50 은 크기·척도를 맞히는 데서 나온 것이고
랭킹으로는 전이되지 않았다.

**[2] 대상 가치 — 완벽히 맞히면 값이 있나**

| | IC vs 선도수익 |
|---|---:|
| **t+h 1일흐름 실제값 (모델의 진짜 목표)** | **+0.1343** |
| t+1~t+h 누적 실제값 (앞서 쓴 오라클) | +0.2108 |
| 직전 1일흐름 (persistence 가 맞히는 것) | −0.0549 |

**모델의 실제 목표에도 값이 있다(+0.134).** 챔프 수익률 신호(+0.057)의 2.3배다.

**[3] 실현 알파** = −0.0778

### 바로잡은 그림

```
목표의 가치        +0.134   (있다)
모델의 예측 품질    +0.112   (persistence +0.210 보다 나쁘다)
실현 알파          -0.078   (예측이 과거 흐름 쪽으로 쏠려 음수 부호를 물려받음)
```

즉 **"예측 가능한 성분에 알파가 없다"가 아니라 "우리 예측이 못한다"** 가 맞다.
모델 예측은 persistence 에 못 미치면서 방향은 과거 흐름(IC −0.055)을 따라가,
가치 있는 성분은 못 잡고 음수 성분만 물려받았다.

### 그래서 이 아이디어는 닫지 않는다

다만 낙관도 제한적이다. persistence 로 예측을 개선해도 그것이 맞히는 것은
`직전 1일흐름`(IC −0.055)이라 알파가 아니다. **가치는 과거로부터 예측되지 않는
성분에 있고, 거기를 잡으려면 전용 학습이 필요하다.**

**다음 실험 (재학습 필요, 4090):** 수급을 MSE 로 복원하는 대신
**횡단면 랭킹 손실**로 학습하는 헤드를 붙인다. 근거:
- 목표 가치가 확인됐다(+0.134, 챔프의 2.3배).
- 현행 예측이 persistence 에도 못 미쳐 **개선 여지가 명확하다**.
- 같은 교훈이 이미 있다 — MSE 정확도와 랭킹 IC 는 다른 물건이다(arXiv 2510.14156).

앞선 "재학습 비용을 정당화 못 한다"는 판단은 **철회한다.** 목표에 값이 있고
현행 예측이 명백히 나쁘다면 그게 정확히 재학습할 이유다.
